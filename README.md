## النشر على GitHub Pages

1. أنشئ مستودعاً جديداً على GitHub باسم `vitas-website` (أو أي اسم تفضله).
2. ارفع محتويات هذا المجلد إلى المستودع.
3. اذهب إلى **Settings → Pages**.
4. تحت **Source** اختر الفرع `main` والمجلد `/ (root)`.
5. احفظ، وخلال دقيقة سيصبح الموقع متاحاً على:
   `https://YOUR_USERNAME.github.io/vitas-website/`

## التقنيات المستخدمة

- HTML5 دلالي
- CSS3 حديث (Flexbox + Grid + متغيرات)
- JavaScript نقي (بدون مكتبات)
- خطوط Google Fonts (Cairo للعربية + Inter)
- Font Awesome للأيقونات
- تصميم متجاوب بالكامل (موبايل / تابلت / ديسكتوب)
- دعم كامل للغة العربية واتجاه RTL
